## `02.` Projetos em destaque

### 📦 Sistema Inteligente de Gestão de Almoxarifado

**Problema:** centralizar o controle de materiais, estoque e movimentações, garantindo rastreabilidade.

**Solução:** aplicação Full Stack com autenticação, gestão de entradas e saídas, permissões e relatórios.

**Stack:** React · TypeScript · Node.js · Express · PostgreSQL · Prisma · Supabase

**O que demonstra:** integração entre camadas, modelagem de dados e aplicação de regras de negócio em logística.

### 🚚 Rastreamento em Tempo Real

**Problema:** dificuldade em acompanhar operações logísticas e a localização de veículos.

**Solução:** painel com geolocalização, mapa, comunicação entre operador e motorista e atualizações em tempo real.

**Stack:** React · WebSocket · PostgreSQL · Supabase · Google Maps API

**O que demonstra:** comunicação em tempo real, integração com mapas e visualização de dados operacionais.

### 📚 Biblioteca Digital

**Problema:** facilitar a descoberta e organização de conteúdos digitais.

**Solução:** plataforma com pesquisa, filtros, favoritos e biblioteca pessoal.

**Stack:** React · TypeScript · Vite · React Router · Context API

**O que demonstra:** componentização, gerenciamento de estado e navegação responsiva.

### 🎬 MovieFlix API

**Problema:** disponibilizar uma interface consistente para consulta e gestão de filmes.

**Solução:** API REST com CRUD, filtros, paginação, validação e documentação Swagger.

**Stack:** Node.js · Express · TypeScript · Prisma · PostgreSQL · Swagger

**O que demonstra:** construção de endpoints, modelagem relacional e documentação técnica.

### ♿ Lacrei Saúde — Desafio Front-end

Interface com foco em **acessibilidade digital, responsividade, componentização e experiência do usuário**.

**Stack:** React · TypeScript · Styled Components · Vite
